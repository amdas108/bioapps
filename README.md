# Bioapps

Набор биоинформатических утилит для работы с биологическими данными.

## FASTQ-фильтратор

Функция `filter_fastq` предназначена для фильтрации FASTQ-последовательностей.

Фильтрация выполняется по трём параметрам:

* GC-составу;
* длине последовательности;
* среднему качеству последовательности.

## Использование

```python
from bioapps import filter_fastq

filter_fastq(
    "input.fastq",
    "output.fastq",
    gc_bounds=(20, 80),
    length_bounds=(50, 150),
    quality_threshold=30,
)
```

После выполнения программы отфильтрованные последовательности сохраняются в папке `filtered`.

## Параметры

### GC-состав

По умолчанию:

```python
gc_bounds=(0, 100)
```

Сохраняются последовательности с GC-составом от 0 до 100 процентов.

Можно задать собственный диапазон:

```python
gc_bounds=(20, 80)
```

В этом случае сохраняются последовательности с GC-составом от 20 до 80 процентов включительно.

Если передать одно число:

```python
gc_bounds=44.4
```

сохраняются последовательности с GC-составом меньше 44.4 процента.

### Длина последовательности

По умолчанию:

```python
length_bounds=(0, 2**32)
```

Можно задать свой диапазон:

```python
length_bounds=(50, 150)
```

В этом случае сохраняются последовательности длиной от 50 до 150 баз включительно.

### Качество

По умолчанию:

```python
quality_threshold=0
```

Качество рассчитывается по шкале Phred+33.
